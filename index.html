Workspace overview

Everything you need to build a stronger password.

Choose a topic from the side menu to open its own page. Your analyzer, live score, risk analysis, and generator stay available in Overview.

01 · Check

Check your password

Type a password in the analyzer to check its length, uppercase, lowercase, number, and special-character requirements. The checks update instantly while you type.

02 · Improve

Improve weak points

Read the suggestions beside the analyzer. Each message explains exactly what is missing, so you can improve the password without guessing.

03 · Score

Understand your score

Your score is calculated from six security checks. 0–2 checks = Weak, 3–4 checks = Medium, and 5–6 checks = Strong.

04 · Generate

Generate a secure key

Use the generator to create a random 16-character password with uppercase letters, lowercase letters, numbers, and symbols.

05 · Protect

Protect every account

Use a different strong password for every account, store it in a trusted password manager, and never share it through messages or email.
